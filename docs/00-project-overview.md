# 00 - نظرة عامة على المشروع

## اسم المشروع
**Production Line Planner**

## الرؤية
نظام تخطيط جاهزية خطوط الإنتاج لشركة أحذية يوفر:
- خريطة حية للمصنع (خطوط → مراحل رئيسية → مراحل فرعية).
- تعيين العمال للمراحل بشكل افتراضي ومؤقت.
- متابعة حالة الحضور/الاستعداد من مصدر ZKTime.
- إشعارات فورية لحالة العامل/الخط/الورديات عبر SignalR.
- واجهة موبايل أولًا ثم تابلت ثم لابتوب.

## الهدف التجاري
- رفع جاهزية الخطوط وتقليل وقت التوقف.
- إعطاء المشرفين والرؤساء رؤية فورية عن توفر القوى العاملة.
- دعم التحويل المؤقت بين المراحل مع عودة تلقائية بعد انتهاء الفترة.

## ما هو داخل النطاق الآن (المرحلة التأسيسية)
- توثيق شامل للبنية، المتطلبات، والـ scope.
- تقسيم واضح لمسؤوليات backend وfrontend.
- نموذج بيانات مبدئي قابل للتنفيذ.
- خارطة طريق تنفيذية من 4 مراحل.

## ما خارج النطاق الآن
- لا نُنشئ مشروع Angular أو .NET الآن.
- لا نُوصّل أي اتصال فعلي بـ SQL Server الآن.
- لا إنشاء ملفات migrations حالياً.
- لا تنفيذ فعلي لخدمات SignalR/هوية/واجهات (حتى الآن، توثيق فقط).

## مبادئ التصميم الأساسية
1. **التركيز على الموبايل أولًا**: كل شاشة قابلة للاستعمال بطبقة لمس طبيعية ومبسطة.
2. **وضوح الحالات**:
   - أخضر: حاضر/جاهز.
   - أحمر: غائب/غير جاهز.
   - أصفر: متأخر/تحذير جزئي.
3. **تقليل التعقيد**: بداية بنواة واضحة قبل إضافة خصائص متقدمة.
4. **فصل المهام**: backend للفورمات/الأدوار/المنطق التكاملي، frontend للعرض والتفاعل وتجربة المستخدم.

## الأدوار
- **Super Admin**: تغييرات حساسة ومؤسسية (تهيئة نظامية/صلاحيات/قواعد صارمة).
- **Admin**: إدارة الخطوط والمراحل، تعيين العمال، حركة العامل المؤقتة.
