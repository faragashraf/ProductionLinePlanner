# Responsive visual QA

Use actual browser/device emulation for every frontend change: Desktop `1440x900`, Android tablet landscape `1280x800`, Android tablet portrait `800x1280`, and mobile `390x844`. Verify RTL, keyboard focus, touch targets, filters, tables, expanded details, loading, empty, and error states. Confirm there is no clipped content, overlap, or unintended horizontal scrolling. Record any unavailable visual review explicitly.
