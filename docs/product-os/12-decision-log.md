# Decision Log

## قواعد السجل

هذا السجل زمني وappend-only. يُضاف قرار جديد عند تغيير مسار Capability، قبول استثناء، اختيار نموذج AI غير اعتيادي، أو اتخاذ قرار حوكمة يؤثر على أكثر من مهمة واحدة. لا يُعدّل القرار السابق؛ تسجل القرارات اللاحقة كتصحيح أو إلغاء صريح.

```mermaid
timeline
    title Product OS Decision Timeline
    2026-07-13 : اعتماد docs/product-os كنظام التشغيل الرسمي لتطوير المنتج
               : تحويل Capability Board إلى Capability Index مع سجل مستقل لكل capability
               : اعتماد Checkpoint كشرط إلزامي قبل Merge
               : اعتماد Terra للمراجعة والتحقق ذوي المخاطر المتوسطة فأعلى
```
