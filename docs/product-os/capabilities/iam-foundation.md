# IAM Foundation

## Purpose

تأسيس إدارة الهوية والوصول والصلاحيات باعتبارها طبقة الحماية المشتركة للمشروع.

يضمن وصول كل مستخدم إلى ما يحتاجه فقط، ويجعل العمليات الحساسة قابلة للمساءلة والتدقيق.

- Product Bible لقواعد الأدوار والصلاحيات المعتمدة.
- طبقة المصادقة والتفويض في backend.
- Audit logging للعمليات الحساسة.
